Comprehensive Curriculum

Our Cyber Security Training Programs

Omtech Corporation offers comprehensive cyber security training programs designed to build strong foundational knowledge as well as advanced, role-based expertise.

Program 01

1. Cyber Security Fundamentals Program

Ideal for beginners and non-security IT professionals
Key Topics Covered:
  • Cyber security concepts & terminology
  • Threat landscape & attack vectors
  • Basics of networking & operating systems
  • Introduction to security controls
  • Cyber hygiene & best practices
Outcome: Participants gain a strong foundation and clarity on cyber security domains and career paths.
Program 02

2. Network & Infrastructure Security Training

Focuses on securing enterprise networks and infrastructure
Key Topics Covered:
  • Network architecture & protocols
  • Firewalls, IDS/IPS & VPNs
  • Network hardening techniques
  • Secure routing & switching concepts
  • Monitoring and logging
⚡ Hands-On Labs:
  • Firewall rule creation
  • Network traffic analysis
  • Attack detection simulations
Outcome: Hands-on mastery in deploying perimeter defense, packet inspection, and resilient network topologies.
Program 03

3. Ethical Hacking & Penetration Testing

Trains participants to think like attackers to defend better
Key Topics Covered:
  • Ethical hacking methodology
  • Reconnaissance & scanning
  • Vulnerability assessment
  • Exploitation techniques
  • Web application security
  • Wireless & network attacks
⚡ Hands-On Labs:
  • Kali Linux-based labs
  • Realistic attack simulations
  • Vulnerability exploitation & reporting
Outcome: Participants learn how to identify weaknesses and recommend remediation measures.
Program 04

4. Security Operations Center (SOC) Analyst Training

Role-based program preparing learners for SOC Analyst roles
Key Topics Covered:
  • SOC structure & workflows
  • SIEM concepts & log analysis
  • Threat detection & alert triage
  • Incident response lifecycle
  • Threat intelligence basics
⚡ Hands-On Labs:
  • SIEM dashboard analysis
  • Incident investigation scenarios
  • Alert correlation exercises
Outcome: Immediate job-readiness for Level-1 & Level-2 SOC Analysts and Incident Responders.
Program 05

5. Cloud & Application Security Training

Addresses security challenges in modern cloud & app environments
Key Topics Covered:
  • Cloud security fundamentals
  • Shared responsibility model
  • Identity & access management (IAM)
  • Secure application development basics
  • Common application vulnerabilities (OWASP Top 10)
Outcome: Ability to audit cloud configurations (AWS/Azure), implement IAM, and secure DevSecOps pipelines.
Program 06

6. Governance, Risk & Compliance (GRC) Training

Focuses on policy, risk, and compliance aspects of cyber security
Key Topics Covered:
  • Information security governance
  • Risk assessment & management
  • Security policies & procedures
  • Compliance frameworks (ISO 27001, standards, regulations)
  • Audit readiness
Outcome: Proficiency in conducting risk assessments, drafting ISMS policies, and preparing organizations for ISO audits.
